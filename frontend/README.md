# Frontend - Agentic AI Travel Platform (Next.js)

Production-grade Next.js App Router frontend built with TypeScript, Tailwind CSS, Lucide Icons, and Supabase Auth.

## Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Configure Environment:**
   ```bash
   cp .env.example .env.local
   ```
   Provide your Supabase URL and Anon Key.

3. **Start Development Server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000).

4. **Build for Production:**
   ```bash
   npm run build
   npm run start
   ```
